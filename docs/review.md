## 가이드 MD·HTML 구성 — 2026-11-01

- IFMS·슈퍼브챗의 `GLANCE.md`와 `docs/tools/md_to_html.py`를 확인한 뒤 같은 화면 구성을 적용했습니다.
- `docs/`의 가이드 6개를 같은 이름의 MD·HTML 쌍으로 관리합니다. 별도 네트워크 요청 없이 HTML 하나로 본문·스타일·설정이 동작하도록 구성했습니다.
- 우측 상단 목차·PDF·설정, 주간/야간·5가지 스킨·12~20px 글자 크기·저장/초기화, 섹션 탭·코드 복사·인쇄용 스타일을 추가했습니다.
- MD 본문과 템플릿을 기반으로 HTML 전체를 재생성하는 도구와 변경 없는 동기화 검사, 문서 시험·브라우저 검사 도구를 추가했습니다.
- 정적 검증에서 가이드 6쌍의 내장 MD 원문 일치, 문서 상대 링크 29개, 설정 패널·5개 스킨·글자 크기·인쇄 요소와 미치환 표식 부재를 확인했습니다. Python 실행 대신 허용된 PowerShell 명령으로 생성·대조했습니다.
- Chrome 미리보기는 현재 실행 환경의 GPU 프로세스 오류로 완료하지 못했습니다. 시각·상호작용 검증 통과로 기록하지 않습니다. Python 문서 시험도 기존 환경 제약으로 미실행입니다.

## 남은 사항

- 실제 Windows 배포 PC에서 GUI·고DPI·서비스 설치·재부팅 검증이 필요합니다.
- PC 범위 DPAPI와 LocalSystem 서비스가 사용하는 폴더는 접근 권한을 관리해야 합니다. 기존 서비스 권한 정책을 유지했습니다.
- `application.py`에 GUI·엔진·서비스가 함께 있습니다. 별도 모듈로 추가 분리하려면 기존 통합 시험의 동등성을 먼저 확보합니다.
- 사용자 known_hosts와 서비스용 known_hosts의 동기화는 기존 정책을 유지했습니다. 서버 교체 시 지문 확인 절차가 필요합니다.
